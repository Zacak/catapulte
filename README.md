# Site de documentation

Le site est entièrement statique.

## Fichiers
- `index.html` : contenu principal
- `style.css` : mise en page et apparence

## Utilisation
Ouvre simplement `index.html` dans un navigateur.

Pour GitHub Pages, dépose les deux fichiers à la racine du dépôt puis active GitHub Pages dans les paramètres du dépôt.
